# qowo-PA | 기숙사 청소분담실

기숙사 공용공간 청소 역할을 쉽게 확인할 수 있는 웹입니다.  
링크에 접속해서 **호실, 청소점검 날짜, 내 침대번호**만 선택하면 사용할 수 있습니다.

## 사용 방법

1. 링크에 접속합니다.  
   https://i0kyung.github.io/qowo-PA/

2. 호실을 선택합니다.  
   예: 404호

3. 청소점검 날짜를 선택합니다.

4. 내 침대번호를 선택합니다.  
   예: 1-1, 2-2, 7-1

5. `청소분담 뽑기 시작` 버튼을 누릅니다.

6. 내 청소분담과 전체 청소분담표를 확인합니다.

## 주요 기능

- 같은 호실과 같은 날짜를 선택하면 모든 기기에서 같은 청소분담표가 나옵니다.
- 내 침대번호를 선택하면 내 청소분담이 맨 위에 표시됩니다.
- 전체 청소분담표도 함께 확인할 수 있습니다.
- `자세히보기`를 누르면 청소 위치와 주의사항을 볼 수 있습니다.
- 체크리스트를 완료하면 청소 확인표에 싸인하라는 안내가 나옵니다.
- 공유 링크를 통해 다른 기숙사생도 같은 날짜의 청소분담을 확인할 수 있습니다.

## 주의사항

- 이 웹은 실시간 채팅이나 서버 저장 기능은 없습니다.
- 체크리스트 완료 상태는 각자 사용하는 기기에 저장됩니다.
- 같은 결과를 보려면 반드시 같은 호실과 같은 청소점검 날짜를 선택해야 합니다.
- 청소가 끝나면 실제 PA 청소확인표에 이름 또는 싸인을 남겨주세요.
